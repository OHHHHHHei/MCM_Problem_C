# 争议量化指标说明文档
# Controversy Quantification Methodology

## 1. 概述 (Overview)

本文档阐述了用于量化选手争议程度的双维度指标体系。该体系基于比赛数据（评审分数、最终排名）构建，不依赖社会舆论数据。

**核心思想**：争议源于"评审意见"与"观众投票"之间的结构性分歧。

---

## 2. 双维度争议框架 (Two-Dimensional Framework)

| 维度 | 名称 | 捕捉的争议类型 | 典型案例 |
|------|------|----------------|----------|
| $S_1$ | 民粹指数 (Populist Score) | 评审认为差，但观众投票保他走很远 | Bobby Bones, Bristol Palin |
| $S_2$ | 遗珠指数 (Robbed Score) | 评审认为好，但观众投票让他早走 | Chandler Kinney, Mya |

### 争议象限图 (Controversy Quadrant)

```
        ↑ S2 (Robbed)
        │
   遗珠型 │  双重争议
  (被冤) │  (极罕见)
        │
────────┼────────→ S1 (Populist)
        │
   无争议 │  民粹型
  (正常) │ (德不配位)
        │
```

## 3. $S_1$ 民粹指数 (Populist Score)

### 3.1 定义

$$S_1 = \max\left(0, \bar{R}_{pct} - P_{pct}\right) \times \left(1 - \sigma_{norm}\right)$$

### 3.2 变量说明

| 变量 | 定义 | 计算方法 |
|------|------|----------|
| $\bar{R}_{pct}$ | 平均评审排名百分位 | $\frac{\bar{R}_{judge} - 1}{N - 1}$ |
| $P_{pct}$ | 最终名次百分位 | $\frac{P_{final} - 1}{N - 1}$ |
| $\sigma_{norm}$ | 归一化排名标准差 | $\frac{\sigma_{rank}}{N - 1}$ |
| $N$ | 赛季参赛人数 | — |

### 3.3 公式解读

- **第一项 $(\bar{R}_{pct} - P_{pct})$**：评审眼中的排名与实际排名的差距
  - 正值 → 评审认为该排更后，但实际排名更前 → 争议
  - 负值 → 实至名归，无争议

- **第二项 $(1 - \sigma_{norm})$**：一致性惩罚因子
  - $\sigma_{norm}$ 小 → 每周都差 → 一致性高 → 争议大
  - $\sigma_{norm}$ 大 → 偶尔表现好 → 有辩护理由 → 争议减弱

### 3.4 计算示例：Bobby Bones (S27)

| 参数 | 值 | 说明 |
|------|-----|------|
| $N$ | 13 | S27有13位选手 |
| $P_{final}$ | 1 | 冠军 |
| $\bar{R}_{judge}$ | 7.7 | 7周平均评审排名 |
| $\sigma_{rank}$ | 1.38 | 排名标准差 |

$$\bar{R}_{pct} = \frac{7.7 - 1}{13 - 1} = \frac{6.7}{12} = 0.558$$
$$P_{pct} = \frac{1 - 1}{13 - 1} = 0$$
$$\sigma_{norm} = \frac{1.38}{12} = 0.115$$

$$S_1 = \max(0, 0.558 - 0) \times (1 - 0.115) = 0.558 \times 0.885 = \mathbf{0.494}$$

## 4. $S_2$ 遗珠指数 (Robbed Score)

### 4.1 定义

$$S_2 = \max(0, Z_{last}) \times \max(0.5, 1 + \bar{Z}_{season})$$

### 4.2 变量说明

| 变量 | 定义 | 计算方法 |
|------|------|----------|
| $Z_{last}$ | 最后一周的 Z-Score | $\frac{Score_{last} - \mu_{week}}{\sigma_{week}}$ |
| $\bar{Z}_{season}$ | 赛季平均 Z-Score | $\frac{1}{W}\sum_{t=1}^{W} Z_t$ |

### 4.3 公式解读

- **第一项 $\max(0, Z_{last})$**：临终表现
  - $Z_{last} > 0$ → 最后一周表现高于平均 → 被淘汰很冤
  - $Z_{last} < 0$ → 最后一周失误 → 被淘汰活该 → 归零

- **第二项 $\max(0.5, 1 + \bar{Z})$**：历史底蕴
  - $\bar{Z}$ 高 → 一直是好学生 → 放大"冤屈感"
  - $\bar{Z}$ 低 → 一直表现平平 → 减弱"冤屈感"
  - 下限 0.5 防止完全归零

- **特殊规则**：若选手获得冠军 ($P_{final}=1$)，强制 $S_2 = 0$。
  - 逻辑：冠军未被淘汰，不存在"被冤枉出局"的可能性。

### 4.4 计算示例：Chandler Kinney (S33)

| 参数 | 值 | 说明 |
|------|-----|------|
| $Z_{last}$ | 1.79 | 最后一周表现极好 |
| $\bar{Z}_{season}$ | 1.16 | 赛季平均高于其他选手 |

$$S_2 = \max(0, 1.79) \times \max(0.5, 1 + 1.16)$$
$$S_2 = 1.79 \times 2.16 = \mathbf{3.87}$$

---

## 5. 综合争议指数 (Optional)

如需单一数值，可使用归一化欧氏距离：

$$\text{Controversy Index} = \sqrt{\left(\frac{S_1}{S_1^{max}}\right)^2 + \left(\frac{S_2}{S_2^{max}}\right)^2}$$

**注意**：$S_1$ 和 $S_2$ 代表不同类型的争议，合并会丢失信息。建议分别报告。

## 7. 模型局限性 (Limitations)

1. **仅衡量结构性分歧**：指标反映的是评审与观众意见的客观差异，而非社会舆论的实际反应。

2. **社会放大效应**：结构性分歧是争议的必要条件但非充分条件。是否形成公共舆论，还取决于媒体关注度、选手知名度等外部因素。

3. **数据局限**：部分早期赛季评委数量或评分制度不同，可能影响跨赛季比较。

---

## 8. 结论

双维度争议框架 ($S_1$, $S_2$) 能够：
- 识别 60-80%+ 的公认争议案例
- 区分不同类型的争议（民粹型 vs 遗珠型）
- 为投票规则改进提供客观依据
