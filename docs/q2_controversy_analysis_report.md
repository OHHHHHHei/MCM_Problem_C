# 争议量化分析报告：S1 与 S2 视角的规则效应

## 1. 概述 (Overview)

本报告详细量化了两种争议类型（S1 民粹型、S2 遗珠型）及其在不同聚合规则（Rank Rule vs. Percentage Rule）下的生存差异。分析基于全 34 赛季、412 位选手的完整数据，重点聚焦于各指标 **Top 10%** 的极端案例。

---

## 2. 争议量化指标定义 (Metrics Definition)

我们定义了两个互补的指标来刻画争议：

### **$S_1$: 民粹指数 (Populist Score)**
> **“评审认为差，但观众投票极高”**

*   **定义**: 衡量选手的**观众人气是否过度偏离其技术水平**。
*   **公式**: $S_1 = \max(0, \bar{R}_{pct} - P_{pct}) \times (1 - \sigma_{norm})$
*   **高分特征**: 评审排名靠后（如第 8-10 名），但凭借海量投票一路晋级甚至夺冠。
*   **典型案例**: Bobby Bones (S27), Bristol Palin (S11)。

### **$S_2$: 遗珠指数 (Robbed Score)**
> **“评审认为好，但过早被淘汰”**

*   **定义**: 衡量**高技术水平选手是否被观众投票“冤杀”**。
*   **公式**: $S_2 = \max(0, Z_{last}) \times \max(0.5, 1 + \bar{Z}_{season})$
*   **高分特征**: 技术分长期处于顶尖水平（Z-Score > 1.0），但在某一赛事周意外出局。
*   **典型案例**: Chandler Kinney (S33), Mya (S9)。

## 4. 规则效应分析 (Rule Impact Analysis)

我们对比了 **Rank Rule (排名制)** 与 **Percentage Rule (百分比制)** 在同一周、同一选手身上的表现。我们分析了上述两组 Top 42 选手在每一周的模拟排名差异。

**Diff 定义**: `Rank_Pct - Rank_Rank`
*   Diff > 0: **Rank Rule 排名更好** (Rank Rule 排名数字更小，例如 Rank 规则第 2 vs Pct 规则第 4)。这意味着该选手在 Rank 规则下更占优势。
*   Diff < 0: **Pct Rule 排名更好**。这意味着该选手在 Pct 规则下更占优势。

### **4.1 对 S1 (民粹型) 选手的影响**

> **核心发现**: 违反直觉的是，**Pct 规则并未一边倒地利好民粹选手**。相反，Rank 规则经常为他们提供更有力的保护。

*   **平均排名差异**: **+0.16** (Rank Rule 略微更好)
*   **分布**:
    *   Rank Rule 更有利 (Diff > 0): **33.0%**
    *   Pct Rule 更有利 (Diff < 0): **22.5%**
    *   无差异 (Diff = 0): **44.5%**
*   **Bottom 2 风险率**: **5.8%** (极低)
*   **深度解析 (The "Capping" Effect)**:
    *   S1 选手通常“严重偏科” (分低票高)。
    *   在 **Pct 规则** 下，如果评委分极低 (如对手的 50%)，需要极其巨大的粉丝票才能填补分差。
    *   在 **Rank Rule** 下，无论评委分多低，最差也就是“倒数第一 (Rank N)”。这个“烂”是有底线的。只要粉丝票拿“第一 (Rank 1)”，总分就能拉回到中上游。
    *   **结论**: Rank Rule 对“极度偏科”选手具有**封顶保护作用**。

### **4.2 对 S2 (遗珠型) 选手的影响**

> **核心发现**: **S2 选手在 Pct 规则下处于明显劣势**，更容易被“黑马”翻盘。

*   **平均排名差异**: **+0.32** (Rank Rule 明显更好)
*   **分布**:
    *   Rank Rule 更有利: **41.5%**
    *   Pct Rule 更有利: **15.2%**
*   **Bottom 2 风险率**: **28.4%** (高危群体)
*   **深度解析**:
    *   S2 选手靠评委分吃饭。
    *   **Pct 规则** 允许高人气的对手利用粉丝票的无限累加效应，直接淹没 S2 选手的评委分优势。
    *   **Rank Rule** 限制了对手粉丝票的“暴击伤害” (最高也就是 Rank 1)，从而保护了技术流选手的生存空间。

### **4.3 Judge Save: 最后的防线**

*   **对 S1 选手**: **无效**。他们只有 5.8% 的概率掉入 Bottom 2，Judge Save 根本抓不到他们。
*   **对 S2 选手**: **至关重要**。他们有 **28.4%** 的概率面临淘汰风险 (Bottom 2)。而一旦进入 Bottom 2，他们凭借全场最高的 S2 技术分，几乎 **100% 会被评委如获至宝地救回**。
*   **结论**: S28 引入的 Judge Save 是专门为 S2 (遗珠型) 选手量身定制的“复活甲”，完美修补了系统漏洞。

---

## 5. 结论 (Conclusion)

通过具体数据分析，我们得出以下反直觉但深刻的结论：

1.  **Rank Rule 既是“双刃剑”也是“平衡器”**：它既保护了技术流免受粉丝狂热的瞬间淹没，也（意外地）保护了极度偏科的民粹选手免受评委低分的毁灭性打击。
2.  **Percentage Rule 更加激进**：它会放大分歧，让“高分更稳、低分更险”，但也让“人气王”有机会用海量选票创造奇迹，或者因为评委分过低而瞬间崩盘。
3.  **Judge Save 是精准手术**：它对 S1 选手影响甚微（因为抓不到），但对 S2 选手是生死攸关的最后一道防线。

**最佳制度建议**: 若要平衡娱乐性 (保护 S1) 和 公平性 (保护 S2)，**Rank Rule + Judge Save** (即 S28+ 现行规则) 是数据证明的**最优解**。
