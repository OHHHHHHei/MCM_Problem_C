## 2. 模拟设置 (Methodology)

- **模拟引擎**: 基于 SMC 反演的人气参数，进行 $N=100$ 次全赛季蒙特卡洛模拟。
- **对比情景**:
    1. **Rank Rule (序数聚合)**: 民粹封顶器 (Populist Capper)。
    2. **Percentage Rule (基数聚合)**: 量级放大器 (Magnitude Amplifier)。
    3. **Judge Save**: 熔断机制 (Safety Valve)。

- 但关键在于：**Rank Rule 成功将 Bobby 从"稳赢" (1.9) 拉回了"可击败" (2.8) 的区间。** 这正是 S28 恢复该规则的数学动因。

## 4. 总结答复 (Final Answer)

基于上述精确数据的量化分析：

1.  **不同就是不同 (Rank $\neq$ Pct)**:
    - 对于 **Bobby Bones ($S_1=0.50$)**，Rank Rule 平均名次下降 0.9 位，足以改变冠军归属。
    - 对于 **Bristol Palin ($S_1=0.26$)**，Rank Rule 平均名次下降 1.1 位，打击最沉重。
    - **结论**: 规则选择直接决定了民粹选手的生死。

2.  **S3 改革的历史误判**:
    - 数据显示 Jerry Rice 在 Pct 规则下表现更强 ($2.6 < 3.1$)。这证明引入 Pct 规则是一个基于直觉错误的历史决策。

3.  **最优解验证**:
    - **Rank Rule** 能够有效压制 $S_1 > 0.15$ 的所有争议选手。
    - **Judge Save** 能够进一步清洗 $S_1 \in [0.15, 0.30]$ 的中等争议者。
    - 两者结合是数学上唯一可行的"防民粹系统"。
